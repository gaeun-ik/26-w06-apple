# 🍎 사과게임

## 게임 소개

8×8 보드에서 드래그로 숫자 사과를 이어 선택하는 게임입니다. 거리가 떨어진 칸도 선택할 수 있으며, 선택한 숫자의 합이 10의 배수이면 해당 칸이 사라집니다. 위쪽 사과들이 아래로 내려와 빈칸을 메우고 맨 위에는 새 사과가 채워집니다. 제거한 칸 수만큼 점수를 얻으며, 최고 기록을 세우면 꽃잎 컨페티가 축하해 줍니다.

## 어떻게 만들었나요

Vanilla JavaScript로 게임 로직을 작성하고 화면 구조와 스타일을 각각 HTML, CSS 파일로 분리했습니다. 포인터 이벤트로 마우스와 터치 드래그를 처리하며, 최고 점수는 브라우저의 `localStorage`에 저장합니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. GitHub Pages 같은 정적 호스팅에도 별도 빌드 없이 배포할 수 있습니다.

## 커스터마이징한 부분

- 목표 합계를 정확히 10이 아닌 10의 배수로 확장했습니다.
- 제한시간을 1분으로 설정했습니다.
- 합을 만든 숫자 칸만 비우고 보충하지 않도록 구성했습니다.
- HTML, CSS, JavaScript를 세 파일로 분리했습니다.
- 최고 기록 저장, 남은 시간 표시, 선택 합계 표시를 추가했습니다.
- 숫자 칸을 빨간 사과 모양으로 꾸몄습니다.
- 인접 칸 제한 없이 넓은 범위의 숫자를 이어 선택할 수 있습니다.
